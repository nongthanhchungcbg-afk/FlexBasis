BÀI THỰC HÀNH

Khám phá flex-basis

Đặt kích thước cơ sở cho Flex Item — rồi quan sát Flexbox điều chỉnh theo trục chính và không gian còn lại.

↔

flex-basis đặt kích thước ban đầu trên trục chính. flex-grow và flex-shrink có thể điều chỉnh kích thước cuối cùng.

ROW → NGANG

VÍ DỤ 01 · ĐƠN VỊ PX

Các basis khác nhau

row

Mỗi Flex Item có kích thước cơ sở riêng trên trục ngang.

Item 1200px
Item 2100px
Item 3150px

flex-basis: 200px · 100px · 150px

.item1 { flex-basis: 200px; }
.item2 { flex-basis: 100px; }
.item3 { flex-basis: 150px; }

VÍ DỤ 02 · PHẦN TRĂM

Basis bằng 50%

50%

Mỗi item bắt đầu với basis bằng một nửa chiều rộng của container.

Item 150%
Item 250%

Gap 10px khiến flex-shrink điều chỉnh một chút để vừa hàng.

.item {
  flex-basis: 50%;
}

VÍ DỤ 03 · TRỤC DỌC

Đổi flex-direction

column

Với column, basis định cỡ theo chiều dọc thay vì chiều ngang.

Item 1100px
Item 2100px
Item 3100px

flex-direction: column · main axis là chiều dọc.

.container {
  flex-direction: column;
}
.item { flex-basis: 100px; }

VÍ DỤ 04 · FLEX-GROW

Phân chia không gian

1 : 2 : 1

Mỗi item bắt đầu ở 100px; phần trống được chia theo tỉ lệ grow.

Item 1grow 1
Item 2grow 2
Item 3grow 1

Basis 100px mỗi item · flex-grow phân phối phần còn lại.

.item1 { flex-basis: 100px; flex-grow: 1; }
.item2 { flex-basis: 100px; flex-grow: 2; }
.item3 { flex-basis: 100px; flex-grow: 1; }

CÁC GIÁ TRỊ ĐẶC BIỆT

auto · initial · inherit

basis
auto

Dùng kích thước width hoặc kích thước phù hợp của nội dung. Ở đây mỗi item đặt width: 150px.

width: 150px
width: 150px
initial

Đặt giá trị ban đầu của thuộc tính: flex-basis trở về auto.

flex-basis: initial;
/* tương đương auto */
inherit

Kế thừa flex-basis 120px từ cha. Thực tế, thường đặt basis trực tiếp trên Flex Item.

inherit · 120px
inherit · 120px
GHI NHỚ

row → basis theo chiều ngang · column → basis theo chiều dọc · flex-grow chia phần không gian dư
